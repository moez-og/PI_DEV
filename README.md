🎯 FinTokhrej – Desktop & Future Web Application
📌 Project Overview
FinTokhrej is a hybrid project that currently exists as a JavaFX desktop application and is designed to be extended into a web application in the future using Symfony (PHP framework).

The goal of the project is to manage and centralize social activities such as places, outings, offers, and events, with rich user interfaces, media support (images), and a clear separation between Front Office and Back Office.

🖥️ Current Version – Desktop Application
The current version of FinTokhrej is a desktop application built with:

Java 17

JavaFX 21

Maven

MySQL / MariaDB

Desktop Features
Modern dashboard-style UI

Front Office (User interface)

Back Office (Admin interface)

Full CRUD operations

Image support (logos, media URLs, UI assets)

Advanced filtering and search

Modular MVC architecture

🌐 Future Version – Web Application (Planned)
In future iterations, FinTokhrej will be integrated into a web platform using:

Symfony (PHP)

Twig templates

RESTful APIs

Shared MySQL database

Planned Web Features
Web-based Front Office for users

Web-based Back Office for administrators

Media management (images, QR codes, uploads)

Synchronization with the desktop application

Responsive UI for browsers

Role-based access control

⚠️ The web version is not yet implemented and represents a planned extension of the project.

🖼️ Media & Images
The project supports images and media content, including:

Application logo

Place and event images (via URLs or uploads)

UI assets (icons, branding)

Future support for image upload in the web version

Images are stored in:

src/main/resources/images/
🧩 Main Modules
Places Management

Offers Management

Designed for desktop-to-web migration
